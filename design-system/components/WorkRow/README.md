# WorkRow

A line in the Work index: who, what changed, and the practice it belongs to.

- Rows sit in one `surface-raised` panel separated by `line` hairlines.
- Left column: client or project in the `label` style. Middle: the outcome as a headline, one supporting sentence. Right: the practice tag.
- Gather work may appear as a row with context but links nowhere deeper.
- Use bracketed placeholders until a figure is confirmed.

The consumer provides client, outcome, supporting line, tag and link.
