# CarouselSlide

LinkedIn PDF carousel slides at 1080 × 1350 (shown here at quarter scale): cover, point, stat, quote and CTA.

- Cover and CTA on `night` with the spark cropped off an edge; interior slides on `surface-raised`.
- One idea per slide, 40 words max. The headline carries the idea without the body.
- Footer on interior slides: wordmark left, page count right.
- Byline is always "Christophe Jammet". The full set lives on page 06 of the Figma kit.

The consumer provides the headline and body per slide.
