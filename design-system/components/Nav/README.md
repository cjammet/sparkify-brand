# Nav

The site header: logo left, four links, one primary button right.

- Use the real logo file (`logo-midnight.svg` on light, `logo-light.svg` on dark); the preview approximates it with live type only for theming.
- Links in `ink-muted`, the current page in `ink` at 500.
- On mobile the links collapse into a menu; the button stays.

The consumer provides the links and the current page.
