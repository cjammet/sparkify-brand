# OfferCard

One card per offer on Home and Advisory, always in a row of three.

- `surface-raised`, `hairline` border, `radius-lg`, `space-7` padding.
- Eyebrow number, a `title` heading, two sentences of `ink-muted` body that start from the client's problem, and a quiet link.
- No icons or illustrations on the card.

The consumer provides number, title, body and link.
