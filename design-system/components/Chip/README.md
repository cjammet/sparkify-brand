# Chip

Filter chips for the Work page and dashboard views; one selected at a time.

- Resting: `surface-raised` with the `hairline` border and `ink-muted` text.
- Selected: `action` fill with `on-action` text.
- `radius-pill`, 14px Geist 500. Keep labels to one or two words.

The consumer provides the labels and the selected state.
