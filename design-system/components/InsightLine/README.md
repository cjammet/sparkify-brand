# InsightLine

One plain-language sentence that says what happened and what to do about it, placed above the charts it summarizes.

- `surface-tint` panel, `radius-lg`, a small spark as the only marker.
- First sentence in `ink` at 500: the finding. Second in `ink-muted`: the recommendation.
- One per dashboard section. If you need three, the section is doing too much.

The consumer provides the finding and the recommendation.
