# CtaBand

The single dark call-to-action band near the end of a page.

- `night` ground, `on-night` headline, `on-night-muted` body, `radius-xl`.
- One per page. The spark may sit large and cropped off the top-right edge; nothing else decorates it.
- Button inverts: `on-night` fill, `night` text.

The consumer provides headline, one sentence and the button.
