# Logos

Sparkify's marks, outlined from Manrope 500 with the eight-point spark. SVGs are the masters; the square PNGs are transparent avatars.

- **logo-midnight.svg**: primary wordmark, Midnight #1C2452 type with the Spark #E5392F spark, for light grounds.
- **logo-light.svg**: the same with Paper #F7F6F2 type, for Night, Midnight or photography.
- **monogram-midnight.svg / monogram-midnight-square.png**: the spark-plus-s abbreviated mark for light grounds and avatars.
- **monogram-light.svg / monogram-light-square.png**: the abbreviated mark for dark grounds.
- **spark.svg**: the spark alone in Spark red, for favicons and anything under about 48px.

Clear space equals the spark's height. The spark is always Spark red, never recolored or outlined.
